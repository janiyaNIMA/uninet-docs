# UniNet Database Architecture & Schema Specification

This document provides a comprehensive blueprint of the database architecture, tables, collections, relationships, and data schemas utilized by the **UniNet** backend system.

UniNet uses a dual-database architecture:
1. **MongoDB Atlas**: Primary authentication credentials store (`users` collection).
2. **PostgreSQL (Neon DB)**: Relational store managed via SQLAlchemy ORM for student profiles, events, societies, portfolio badges, recruitment pipelines, and account settings.

---

## 1. MongoDB Collections

### 1.1 `users` Collection (Authentication Store)
Stores sensitive authentication credentials.

| Field Name | Type | Key / Constraint | Description |
| :--- | :--- | :--- | :--- |
| `_id` | ObjectId | Primary Key | Unique BSON identifier generated by MongoDB |
| `username` | String | Unique Index, Required | Unique student / user handle |
| `email` | String | Unique Index, Required | Institutional email address |
| `password_hash` | String | Required | Securely hashed password (Bcrypt / Werkzeug) |
| `role` | String | Default: `'student'` | System role (`'student'`, `'excom'`, `'admin'`) |

## 2. PostgreSQL Tables (SQLAlchemy Models)

### 2.1 `users` Table
Stores student profile metadata, gamification scores, badge tiers, and academic history.

- **Model**: `User`
- **Table Name**: `users`

| Column Name | Data Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `id` | `VARCHAR(10)` | Primary Key | Custom User ID string (e.g., `'STU001'`) |
| `username` | `VARCHAR(80)` | Unique, Not Null | Account username |
| `email` | `VARCHAR(120)` | Unique, Not Null | User email address |
| `password_hash` | `VARCHAR(256)` | Nullable | Fallback local password hash |
| `role` | `VARCHAR(20)` | Default: `'student'` | Access role (`'student'`, `'excom'`, `'admin'`) |
| `full_name` | `VARCHAR(120)` | Default: `'Jane Doe'` | Full display name |
| `phone` | `VARCHAR(50)` | Default: `'+94 77 123 4567'` | Contact phone number |
| `university` | `VARCHAR(150)` | Default: `'Wayamba University...'` | University name |
| `faculty` | `VARCHAR(150)` | Default: `'Faculty of Applied...'` | Faculty / Department name |
| `degree_stream` | `VARCHAR(150)` | Default: `'BSc (Hons)...'` | Enrolled degree program |
| `batch` | `VARCHAR(50)` | Default: `'Batch of 2022/23'` | Academic intake batch |
| `badge_tier` | `VARCHAR(50)` | Default: `'Gold'` | Gamified tier (`'Gold'`, `'Silver'`, `'Bronze'`) |
| `total_points` | `INTEGER` | Default: `530` | Total co-curricular points |
| `next_tier_points` | `INTEGER` | Default: `600` | Points required for next badge tier |
| `skills` | `TEXT` | JSON Array String | List of student skills |
| `interests` | `TEXT` | JSON Array String | List of student interests |
| `academic_modules` | `TEXT` | JSON Array String | List of enrolled module codes & names |
| `public_profile_enabled` | `BOOLEAN` | Default: `True` | Public profile visibility setting |
| `created_at` | `DATETIME` | Default: `UTC Now` | Account creation timestamp |
